# Midterm Express App

A Node.js web app built using the Express framework with the Handlebars engine. 

## Prerequisates

Before deploying this application, make sure you have the following installed:
* Node.js
* npm (comes bundled with Node.js)
* Git

## Local setup 

Follow these steps in order to run the project successfully on your machine:

1. Clone or download the project files
2. Open your terminal and navigate tot he project root folder 
3. Install the necessary dependencies listed within the "package.json" file
4. Start the application server 
5. Open your web browser and navigate to https://localhost:3000;
